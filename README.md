# ✈️ Fun Travel — Travel Plans Store

**Fun Travel** is an Arabic, right-to-left travel website prototype for discovering curated travel plans, filtering trips by destination and preferences, and adding selected plans to a shopping cart.

> A lightweight front-end project built with HTML, CSS, and vanilla JavaScript.


## 🌍 Website Sections

### 1. Homepage
Introduces the Fun Travel brand and helps visitors start exploring travel plans.


### 2. Travel Plans
Presents available travel packages with destination details, trip duration, interests, and estimated prices.


### 3. Discover Your Trip
Visitors can filter travel plans by destination, interests, and budget to find options that match their preferences.


### 4. Shopping Cart
Visitors can add multiple travel plans, remove selected plans, and view an estimated total before proceeding to the demo checkout.


### 5. Contact
A contact section gives visitors a place to find the business contact information.


## ✨ Features

- Arabic interface with right-to-left layout.
- Responsive layout for desktop and mobile screens.
- Travel plan cards with destination, duration, interests, and estimated price.
- Filters for destination, interests, and budget.
- Shopping cart with add and remove actions.
- Estimated cart total.
- Demo checkout form for customer details.
- Embedded destination illustrations to avoid broken external image links.

## 🧰 Built With

- **HTML5** — page structure.
- **CSS3** — styling and responsive layout.
- **Vanilla JavaScript** — filtering, cart interactions, and demo checkout.

## 🚀 Getting Started

No package installation or build tools are required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Browse travel plans, try the filters, and add plans to the cart.

```bash
git clone <your-repository-url>
cd <your-repository-folder>
```

Then open `index.html` in your browser.

## ⚠️ Project Status & Notes

This is a **front-end prototype**:

- Travel plans and prices are sample content and should be updated before public business use.
- Checkout is for demonstration only; no real payment is processed.
- Orders are not stored on a server or automatically sent to the business.
- The cart is client-side and is not a persistent, account-based cart.
- The destination images in this README are illustrative references; the website itself uses embedded destination illustrations.
